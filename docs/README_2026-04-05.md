## Quick Overview

**Vanto Zazi** is a hybrid MLM/CRM progressive web app for APLGO network marketing distributors. Built with React 18, TypeScript, Tailwind CSS, and Lovable Cloud (Supabase backend).

### Key Capabilities
- 📇 22+ field contact management with duplicate detection
- 📊 Dashboard with KPIs, AI news briefing, and follow-up tracking
- 💬 WhatsApp outreach with 13-category message template library
- 🛒 Order management with AI Smart Paste from backoffice
- 📈 Deals pipeline with GO-Status rank valuations
- 🤖 ZAZI AI Copilot embedded across all pages
- 🔥 90-Day Momentum Run (RESET & RISE methodology)
- 📱 Installable PWA (desktop, Android, iOS)
- 🔌 Chrome extensions for WhatsApp sync and follow-up coaching

---

## Tech Stack
- **Frontend:** React 18 + Vite 5 + Tailwind CSS + TypeScript
- **Backend:** Lovable Cloud (PostgreSQL, Auth, Edge Functions, Storage)
- **AI:** Lovable AI (Gemini/GPT, no API key required)
- **PWA:** vite-plugin-pwa with Workbox
